🌳 Representación Gráfica del Árbol del DOM

Estructura jerárquica de etiquetas que componen las páginas web de este proyecto, desde el nodo raíz hasta los elementos de renderizado interactivo.

Jerarquía General del Proyecto (HTML Document Object Model)

<html> lang="es" Nodo Raíz del Documento
<head> Metadatos y Recursos
<meta> <title>
<link rel="stylesheet">
<script src="p5.js">
<body> Cuerpo Visible
<header>
<nav> <ul> <li> <a>
<main id="main-content">
<h1>, <p>, <div id="sketch-holder">
<footer>
<p>

Detalle del Contenedor de Gráficos (Canvas Inyectado por p5.js)

Cuando la librería p5.js se ejecuta mediante la función canvas.parent('sketch-holder'), modifica dinámicamente el DOM insertando el elemento nativo <canvas> dentro del contenedor HTML: 

<div class="sketch-container" id="sketch-holder">
  <canvas id="defaultCanvas0" width="400" height="400" class="p5Canvas" style="width: 400px; height: 400px;"></canvas>
</div>
