# graficos-khan
# Despliegue de Gráficos – Khan Academy → Código Nativo

Sitio web que adapta los dibujos realizados en Khan Academy a código estándar (HTML + CSS + JavaScript con p5.js).

## Contenido del sitio

- **index.html** → Página principal con menú de navegación
- **teoria.html** → Sección informativa sobre `<canvas>` y p5.js
- **dientes.html** → Dientes de conejo (Bucktooth Bunny)
- **cena.html** → ¿Qué hay de cena? (What's for dinner?)
- **nevado.html** → Día nevado soleado (Sunny Snowy Day)
- **muneco.html** → Muñeco de nieve (Super Snowman)
- **styles.css** → Estilos del sitio

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript
- Librería **p5.js** (para dibujar en canvas)
