Apuntes teóricos sobre las herramientas usadas para crear los gráficos.

1. La etiqueta HTML <canvas> y el contexto 2D

¿Qué es <canvas>?

<canvas> es un elemento HTML5 que crea un área de dibujo (bitmap) en la página. Por sí solo no dibuja nada: necesitamos JavaScript para obtener un contexto de renderizado y pintar sobre él.

Crear un canvas

<canvas id="miCanvas" width="400" height="400"></canvas>

Obtener el contexto 2D

const canvas = document.getElementById("miCanvas");
const ctx = canvas.getContext("2d");  // Contexto de renderizado 2D

Métodos principales del contexto 2D

  • fillRect(x, y, ancho, alto) – rectángulo relleno
  • strokeRect(x, y, ancho, alto) – rectángulo solo contorno
  • beginPath() / closePath() – iniciar/cerrar un camino
  • moveTo(x, y) / lineTo(x, y) – líneas
  • arc(x, y, radio, inicio, fin) – arcos y círculos
  • fill() / stroke() – rellenar o dibujar el contorno
  • fillStyle / strokeStyle – color de relleno y de línea
  • clearRect(x, y, ancho, alto) – borrar una zona

Ejemplo mínimo con canvas nativo

const canvas = document.getElementById("miCanvas");
const ctx = canvas.getContext("2d");

ctx.fillStyle = "skyblue";
ctx.fillRect(0, 0, 400, 400);

ctx.fillStyle = "yellow";
ctx.beginPath();
ctx.arc(100, 80, 40, 0, Math.PI * 2);
ctx.fill();

El sistema de coordenadas empieza en la esquina superior izquierda (0,0). El eje X crece hacia la derecha y el eje Y hacia abajo.

2. Fundamentos de la librería p5.js

¿Qué es p5.js?

p5.js es una librería de JavaScript creada para hacer más accesible la programación creativa (dibujo, animación e interacción). Es la evolución moderna de Processing.js, la misma tecnología que usa Khan Academy en sus retos de dibujo.

Cómo incluirla

<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.0/p5.min.js"></script>

Estructura básica de un sketch

function setup() {
  createCanvas(400, 400);
  background(220);
}

function draw() {
  // Este bloque se ejecuta muchas veces por segundo
}

Funciones de dibujo más usadas

  • ellipse(x, y, ancho, alto) – elipse o círculo
  • rect(x, y, ancho, alto) – rectángulo
  • triangle(x1,y1, x2,y2, x3,y3) – triángulo
  • line(x1, y1, x2, y2) – línea
  • arc(x, y, ancho, alto, inicio, fin) – arco
  • fill(r, g, b) / stroke(r, g, b) – color
  • noFill() / noStroke() – sin relleno o sin contorno
  • background(r, g, b) – color de fondo

Ventajas de p5.js frente al canvas nativo

  • Sintaxis mucho más simple y cercana a Processing (la de Khan Academy).
  • Maneja automáticamente el bucle de animación con draw().
  • Ideal para dibujos, animaciones e interacciones creativas.
